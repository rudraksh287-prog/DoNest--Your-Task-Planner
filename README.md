
# DoNest

DoNest is a simple and functional Todo App built using React, Vite, and Tailwind CSS. This project was mainly created to learn React fundamentals, component-based architecture, state management, and how Vite works in a modern frontend workflow.

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Persistent storage using localStorage
- Responsive and clean interface

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- UUID
- React Icons

---

## Purpose of the Project

This project focuses mainly on:
- Understanding React basics
- Managing state using `useState`
- Using `useEffect` with localStorage
- Learning component structure
- Exploring the Vite workflow
- Styling with Tailwind CSS

Rather than focusing heavily on advanced UI design, the goal of this project was to build a strong understanding of functionality, frontend structure, and React fundamentals as a first React + Vite project.

---

## Project Setup

Clone the repository:

```bash
git clone <your-repo-link>


Go to the project folder:

```bash
cd donest
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
